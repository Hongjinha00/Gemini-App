## 🚀 기능


- ⚡ **즉시 호출**  
전역 단축키를 통해 언재든 빠르게 사용할 수 있습니다.

- 🔄 **AI Studio 지원**  
Gemini Web App과 AI Studio를 둘 다 사용할 수 있습니다.

- 📌 **항상 호버**  
창이 항상 고정돼 유연한 멀티태스킹이 가능합니다.

- 🌙 **백그라운드**  
언재든 호출해 작업을 이어서할 수 있습니다.


## 🛠️ 개발

```bash
git clone https://github.com/Hongjinha00/Gemini-App.git
cd Gemini-App
npm install
npm start
```

**빌드:**
```bash
npm run build:win      # Windows
npm run build:linux    # Linux
npm run build:mac      # macOS
```
